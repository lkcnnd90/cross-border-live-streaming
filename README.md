## 5M 能不能直播，要看这 5M 是哪种 5M

行业里给的口径比较一致：手机开播 5M 起步，电脑推流 10M 起步，1080P 电脑直播建议 10–20M 或以上，720P 大约要 4Mbps 以上上传，1080P 尽量到 10Mbps 以上。多设备按“设备数 × 单设备需求”叠加，再留冗余。

5M 的适用边界很窄：单台手机、720P 或常规画质、真人出镜或普通带货、没有其他设备抢网络。这个配置能开播，但“5M 能播”和“5M 适合所有场景”是两回事。每天播 6 小时以上的号，或者要连麦、要动态画面多的品类，5M 没有余量吸收波动。另外，这里的 5M 指的是能稳定跑住的带宽，不是测速软件偶尔跳到的峰值。

WePC 的套餐里，5M 出现在哪？马来双 ISP 家宽写着“超流量限速 5M”。也就是说 2TB 用完之后，这条线掉到 5M，恰好卡在“单机 720P 能播、多设备或 1080P 推流不能播”的那条线上。如果你按不限量做预算，超量那个月就得回到单机低码率，或者临时加购流量。

套餐标称的 100–200Mbps 是端口带宽，说明这台机器出去不窄，不代表国内连过去推流就稳。这一段路走的是公网，晚高峰该抖还是抖，这也是官网劝你加中转的原因。

## 带宽之外的三个变量

直播卡顿的原因里，带宽不够排不到第一。抖动大、出口 IP 不干净，这两项更常见。IP 被平台标记过，带宽再大也是限流或零播放。

共用出口 IP 跑多个账号是第二个坑。行业内的普遍建议是一个 IP 对应一个直播账号，同一 IP 登太多号容易触发风控。WePC 每个节点给 1 个独立 IPv4，按号配机是最稳的用法，也是成本最高的用法。

DNS 是第三个容易被忽略的点。IP 落在目标国，解析却走了别处，平台侧一样能看出来。拿到机器后可以用 ipleak.net 查两件事：IP 归属地是不是目标市场，DNS 是不是落在当地 ISP。配置交付时把 DNS 和时区一起设好，比事后排查省事。

正式开播前，用真实 TikTok 直播环境跑一场，别只看测速结果。测速跑满分、开播掉帧的情况很常见。

## 常见问题

**WePC 卖的是专线还是 VPS？**
VPS。每个节点一台独立机器，含独立 IPv4、端口带宽和月流量，国内连接质量取决于你选的节点和中转方案，官网逐节点标注了是否需要中转。

**5M 能带几台设备直播？**
按行业口径，5M 对应单台手机、720P 左右画质。每增加一台设备大约再加 5M，电脑推流单台就要 10M 起。WePC 的 5M 是超流量后的限速值，不是套餐标称带宽，别把它当成常态速度。

**一定要买中转吗？**
看节点。纽约 Cogent 标了无需中转，韩国、日本、新西兰、阿联酋、巴西、马来、西班牙都建议或必须中转。只发视频可以先不买，开播前建议先用真实环境测一场再决定。

**2TB 流量够播多久？**
按 720P 约 4Mbps 估算，每小时上行 1.8GB 左右，每天 8 小时约 430GB/月。单账号够用，多账号或高码率要盯着余量。

**和 499 元/月的专线比，差在哪？**
差在链路的端到端负责制和售后。专线把国内入口到海外出口整条包下来，带 SLA；WePC 只出海外那一端，价格低一个量级，稳定性要自己拼。
